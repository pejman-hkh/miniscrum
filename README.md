# Mini Scrum Board – Next.js Kanban App

A lightweight **Scrum / Kanban board** built with **Next.js**, **Prisma**, and **Docker**.  
Designed for simple project and task management with drag & drop support.

---

## Features

- Kanban boards (Todo / Doing / Done)
- Drag & Drop task management
- Task ordering
- JWT authentication
- Protected API routes
- Docker & Docker Compose support

---

## Tech Stack
Next.js · TypeScript · Prisma · SQLite · Tailwind CSS · dnd-kit · i18n · Docker · Nginx

---

## Getting Started

```bash
npm install
npx prisma migrate dev
npm run dev
‍‍‍
```

## Docker

```bash
docker-compose up -d --build
```
